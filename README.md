# VELORA fragrance landing page

## Run it

Open `index.html` in a modern browser. The page is a standalone responsive frontend and needs no build tools or package installation. Google Fonts are loaded online; system fonts are used if unavailable.

## Concept and research

VELORA is presented as the user's proposed affordable-luxury brand, not as an existing perfume. Daybreak is an original scent direction suggested by public market signals. The ₹399 / 50 ml figure is an illustrative target, not a live offer or validated production price.

Public retailer rankings and review counts do not isolate school or college buyers, and are not comprehensive national sales data. No student survey was conducted. Prices, ratings, and stock change; wear time depends on the wearer and conditions. The page avoids a quantified longevity guarantee pending actual product testing.

Research links and the summary are included in the page's “Our research” section.
